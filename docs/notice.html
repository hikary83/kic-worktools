📢 공지사항 생성

CMS 업데이트 공지 이미지와 공지글을 생성합니다.

사용 방법
왼쪽에 내용을 입력하면 오른쪽 미리보기가 자동으로 바뀝니다. 우측 상단에서 디자인 시안을 바꿔가며 비교할 수 있습니다.
기본 정보
섹션 문구
주요 반영 사항
※ 최대 9개까지 권장합니다. 4개 이상이면 자동으로 2~3열 배치됩니다.
확인 필요 사항
※ 긴 문구도 카드 폭에 맞춰 자동 줄바꿈됩니다.
옵션

미리보기

다운로드 시 미리보기 영역만 이미지로 저장됩니다.
