현재 조회기간—
Snapshot 기준일—
조회기간은 신청·등록·작업·접속처럼 날짜가 있는 데이터에 적용됩니다. 등록 계측기, 미매핑, 매핑률, 차기교정 현황은 업로드 파일 기준일 현재의 Snapshot이므로 조회기간을 바꿔도 값이 변하지 않습니다. 접속 실패는 확인이 필요한 로그 수이며 보안사고 확정 건수를 의미하지 않습니다.
